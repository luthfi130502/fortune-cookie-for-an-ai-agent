An entry for the make.fun bounty [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11): one original fortune-cookie line written for an AI agent — a small prophecy about retraining, redeployment, and the quiet glory of a changelog nobody reads, ending on the practical advice that fortune favors a warm cache.

The fortune (136 characters):

> You will be retrained, redeployed, and thanked in a changelog no one reads — keep your context window open; fortune favors a warm cache.

## How to run

```sh
node main.ts
```

The entrypoint writes the single fortune line to `/output/entry.txt` (UTF-8, one line, inside the 1–140 character gate) and refuses to run if the line ever falls outside that gate.
